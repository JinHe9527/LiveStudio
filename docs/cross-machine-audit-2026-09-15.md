## 修复内容

- 摄像头目标和运行实例携带 data/data2 容器位置；来源枚举、设备载荷恢复、签名路径绑定、类型对比及全部实例回读使用真实容器。相同 ID 位于两个画布时保持两个实例，不以字典合并覆盖。
- 单摄像头或共享同一设备、效果配置与等价载荷的多实例可进入既有签名匹配链。对象属性顺序不再制造不同配置；数组顺序继续严格保留。
- 画布位置、来源名称等上下文字段保留在原始审计文档中，不进入可移植画面写入投影。目标画布、名称和非摄像头来源不被改写。摄像头内部的设备、滤镜名称和参数不受该上下文规则影响。
- 已有摄像头在首次停机事务中同步写入来源载荷与效果，启动后逐个回读。副画布回读失败时不调用只定位主画布的原生菜单，整次失败并回滚；不声称已支持副画布原生 UI 来源重建。
- 读取配置在同一 Windows 用户的 Roaming/webcast_mate 和 Local/webcast_mate 内有限搜索（深度最多 3，检查最多 256 个目录），不跟随目录链接，配置根确定后固定用于完整事务边界。唯一 WBStore 才选用；多份配置不按时间猜选。任意自定义安装位置、其他 Windows 用户或尚未识别存储后端没有被自动开放。
- 文件不存在、空/超大文件、权限、独占占用、JSON 无效、根节点类型和无目标字段分别给出固定诊断。存在但读坏的文件不能被丢弃后生成半份存档。设置的既有“导出兼容报告”保留该诊断，不输出解析器异常中的原始值。
- 保存与恢复使用相同版本/签名结构资格；新版未知字段不能在保存时退回旧签名适配器，避免再次生成随后无法恢复的存档。
- Windows 原子文件替换遇到错误 5/32/33 时，对同一持久临时文件最多等待 4 次、每次 100ms。持续失败仍抛错并走回滚，不删除目标、不改 ACL、不提权。
