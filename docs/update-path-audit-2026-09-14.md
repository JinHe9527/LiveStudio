## 实际更新链

1. Desktop 的 `CheckForUpdatesAsync` 直接调用 `ApplicationUpdateService`，不经过 LocalAgent、OBS WebSocket 或云端账号服务器。
2. 编译元数据 `LiveStudioUpdateManifestUrl` 非空时尝试该 HTTPS 清单；为空时访问 `https://github.com/JinHe9527/LiveStudio/releases/latest`。
3. 从公开重定向解析版本，检查版本化的 Setup 和 SHA-256 资产。
4. 下载经允许主机的 HTTPS 重定向；安装前检查 SHA-256、Publisher 和证书指纹，再以 UAC 启动同一 Setup。
5. Setup 验证内嵌 MSIX、签名和安装条件后升级；桌面启动逻辑检查并启动同包 Agent。

## 修复

- 原检查仅接受资产 HTTP 302 即视为可下载，未核对 CDN。现在清单与资产请求跟随受信任重定向，验证最终 HTTP 成功；最终 404、非法主机、缺少 Location 的重定向不再误报可用。
- 检查总期限 30 秒，已配置镜像最多使用 10 秒，超时或网络错误后仍可尝试 GitHub；调用方取消保持取消语义。
- 网络异常保留实际请求主机、原异常和代理连接拒绝的检查建议；没有静默关闭代理、绕过签名或降低 HTTPS 要求。
- 桌面补全检查取消、下载取消和下载超时反馈，清理旧更新状态并允许重试。
