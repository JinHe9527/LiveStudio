# LiveStudio v0.1.33

## 自动错误记录与一键导出诊断包

测试电脑遇到问题后，打开 **设置 → 错误诊断 → 导出诊断包**，将生成的 ZIP 通过 QQ 或微信发给开发者，并说明操作步骤、实际表现及大致发生时间。无需注册额外账号，也不需要联网或连接 Agent 才能导出已有记录。

- 自动记录界面、执行端、安装和恢复流程中的已接入错误，包括直播伴侣兼容检查失败。
- 诊断包包含错误类型、固定原因码、代码位置、发生时间及次数、软件版本和脱敏兼容摘要。
- 不打包原始配置、密码、账号、用户名路径、截图或原始安装日志。
- 无错误记录时仍可导出环境摘要；损坏、不可读或过大的日志会明确标注跳过数量。
- 当前采用本地记录和手动发送方案；未开通自动提交 GitHub，界面隐藏未配置的网络提交入口。

本版本重点补齐异机排障证据，不代表此前失败的两台电脑已完成复测或全部恢复能力已通过真机验收。

## 更新

现有用户可在软件中选择“设置 → 检查更新 → 下载并安装”，也可以从本 Release 下载 `LiveStudio-Setup.exe`。

本地验证：455 项测试通过，Release 构建和格式检查通过。正式安装器和 MSIX 由 Windows Release 工作流在测试及依赖漏洞门通过后构建并检查签名。
