# LiveStudio 第二台 Windows 电脑验收工具

本工具只调用公开安装包随附的正式 `LiveStudio.Agent` 本机控制协议，不直接修改 OBS 配置文件或直播伴侣原生存储。

## 文件

- `Run-SecondMachineValidation.ps1`：只读环境检查和可选的五轮事务恢复。
- `1-检查环境.cmd`：默认只读，不导入、不恢复。
- `2-执行五轮恢复测试.cmd`：要求输入 `RESTORE-5` 后，固定包签名通过才会导入并执行五轮恢复。
- `3-诊断保存失败.cmd`：通过正式 Agent 执行一次保存；失败时确认没有新增半份存档，并把精确错误和最近操作写入 `results`。

## 安全边界

- 安装器和测试包使用固定 SHA-256；测试存档使用固定签名者指纹。
- 五轮模式只在 OBS、直播伴侣、LiveStudio Desktop 与 Agent 均满足运行条件时继续。
- 设备对应只在当前应用只有一个候选设备时自动保存；候选不唯一时停止并要求使用正式界面手动选择。
- 每轮只调用 `RestoreSnapshot`，由生产恢复链执行 Preflight、永久恢复前备份、跨应用持久事务、逐字段回读和失败回滚。
- 每轮必须新增且只新增一份恢复前自动备份，并产生 `Succeeded` 操作记录，否则本轮报告失败。
- JSON 报告仅记录版本、硬件 ID、驱动、哈希、状态和恢复结果，不保存账号、Cookie、Token、推流密钥或画面参数原值。
- 保存诊断不会写入 OBS 或直播伴侣配置；成功时只新增一份正常签名存档，失败时要求存档数量保持不变。

五轮成功只能形成第二台电脑的 `Mapped` 证据。仓库的正式 `Verified` 标记仍需完整的跨机器循环和故障矩阵，工具不会擅自提升证据等级。
